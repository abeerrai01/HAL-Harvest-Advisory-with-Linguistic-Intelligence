# Payal 2.0 LiveKit Connection Fix

## Problem
Frontend error: `could not establish signal connection: no permission to access the room`

## Root Cause
The LiveKit token generated by the backend doesn't have the correct room permissions. The token must include:
1. The exact room name in the grant (must match the roomName returned in response)
2. `roomJoin: true` permission
3. Valid identity

**CRITICAL**: The frontend must use the `roomName` returned by the backend - not a hardcoded room name!

## Backend Fix Required

The backend at `https://theabeerrai-payal-2-0.hf.space` needs to:

### 1. Generate tokens with correct permissions

```python
from livekit import api
import uuid
import os

LIVEKIT_URL = os.getenv("LIVEKIT_URL")
LIVEKIT_API_KEY = os.getenv("LIVEKIT_API_KEY")
LIVEKIT_API_SECRET = os.getenv("LIVEKIT_API_SECRET")

@app.post("/start")
def start_payal():
    try:
        # Generate unique room name
        room_name = f"payal-room-{uuid.uuid4().hex[:6]}"
        identity = f"farmer-{uuid.uuid4().hex[:6]}"
        
        # Create LiveKit access token
        at = api.AccessToken(
            LIVEKIT_API_KEY,
            LIVEKIT_API_SECRET,
            identity=identity
        )
        
        # CRITICAL: Add grants with room name
        at.add_grant(
            api.VideoGrant(
                room_join=True,      # Must be True
                room=room_name,      # Must match the room name exactly
                can_publish=True,
                can_subscribe=True,
            )
        )
        
        token = at.to_jwt()
        
        # Return all required fields
        return {
            "status": "ok",
            "message": "Payal is ready!",
            "livekitUrl": LIVEKIT_URL,
            "token": token,
            "identity": identity,      # Include identity for participant label
            "roomName": room_name      # CRITICAL: Return the exact room name
        }
    except Exception as e:
        return {"error": str(e)}, 500
```

### 2. Fix Worker Launch Issue

**Problem**: You're seeing `Missing command` errors because the worker is launched incorrectly.

**Wrong**:
```python
subprocess.Popen(["python", "assistant.py"])
```

**Correct**:
```python
subprocess.Popen(["python", "assistant.py", "run"])
```

The `assistant.py` script requires the `run` command argument.

### Key Points:
1. **Room name must match exactly** - The token's `room` grant must be the exact same string as the room name
2. **roomJoin must be True** - Without this, the client cannot join
3. **Identity should be unique** - Use the farmer ID or session ID

## Complete Backend Example (FastAPI)

```python
from fastapi import FastAPI
from fastapi.responses import JSONResponse
import os
import uuid
from livekit import api

app = FastAPI()

# Get credentials from Hugging Face Secrets
LIVEKIT_URL = os.getenv("LIVEKIT_URL")
LIVEKIT_API_KEY = os.getenv("LIVEKIT_API_KEY")
LIVEKIT_API_SECRET = os.getenv("LIVEKIT_API_SECRET")

@app.get("/")
def home():
    return {"status": "ok", "message": "Payal 2.0 backend is live 🌾"}

@app.post("/start")
def start_payal():
    try:
        # Generate unique room name and identity
        room_name = f"payal-room-{uuid.uuid4().hex[:6]}"
        identity = f"farmer-{uuid.uuid4().hex[:6]}"
        
        # Create LiveKit access token
        at = api.AccessToken(
            LIVEKIT_API_KEY,
            LIVEKIT_API_SECRET,
            identity=identity
        )
        
        # Add grants with room permissions
        at.add_grant(
            api.VideoGrant(
                room_join=True,      # CRITICAL: Allow joining room
                room=room_name,       # CRITICAL: Exact room name
                can_publish=True,     # Allow publishing audio
                can_subscribe=True,   # Allow subscribing to audio
            )
        )
        
        token = at.to_jwt()
        
        # Return all required fields
        response = {
            "status": "ok",
            "message": "Payal is ready!",
            "livekitUrl": LIVEKIT_URL,
            "token": token,
            "identity": identity,
            "roomName": room_name
        }
        
        return JSONResponse(content=response, status_code=200)
        
    except Exception as e:
        return JSONResponse(
            content={"error": str(e), "message": "Failed to start Payal session."},
            status_code=500
        )
```
